- [ ] 同目录有 `.wasm` / `.pck`（或 Godot 导出的配套文件）

- [ ] 使用 https 或 App 内允许的本地/桥接加载（勿依赖裸 `file://`）

- [ ] 允许运行 WebAssembly

- [ ] 首包体积与加载时间可接受（或已定 CDN/分包方案）
