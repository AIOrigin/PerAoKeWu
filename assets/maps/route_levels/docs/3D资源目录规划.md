## 2. 总原则

1. **正式资源只放** `assets/maps/route_levels/models/`（游戏代码只引用这里）。  
2. **收件箱 / 生成中间产物** 放 `assets/maps/route_levels/_inbox/`（或暂留根目录 mvp，但**禁止**新代码直接 `res://mvp…`）。  
3. 路径与文件名：**英文小写 + 下划线**；角色 id 与 `CharacterRoster` 一致（`elsa` / `rook`）。  
4. 每个可运行模型：`*.glb`（或带动画的 `*.fbx`）+ 贴图放同级 `textures/` 或 glb 内嵌。  
5. **赛道主体继续程序挤出**（`RoadMeshBuilder`），不强制做整条路 mesh；仅材质/贴图进 `track/`。  
6. 一层语义一个目录：**谁用、什么距离、什么玩法**，不按「第几批素材」分。

## 4. 分类对照（放哪）

| 类别 | 放哪里 | 举例 | 不要放 |
|------|--------|------|--------|
| 奔跑主角 | `models/characters/<id>/` | Elsa / Rook 姿态与动画 | UI 立绘、概念图 |
| 玩法障碍 | `models/obstacles/<动作>/` | 跳栏、铲门、闪避柱、orb | 路旁装饰石头 |
| 2.5D 障碍图 | `runner_60s/obstacles_2_5d/` | energy_orb_*.png | glb |
| 赛道材质 | `models/track/textures` + shader | 全息路俯视图、沙石 albedo | 整条赛道 glb（默认不用） |
| 近景装饰 | `models/environment/midground/` | 霓虹牌、珊瑚、陨石 | 可撞死玩家的主障碍 |
| 远景地标 | `models/environment/distant/` | 塔、飞船、舱体 | 需要精确碰撞的物体 |
| 据点建筑 | `models/environment/buildings/` | 医疗/水源/穹顶 | 星系小行星球 |
| 星球/恒星 | `models/environment/planets|stars/` | 星系地图用 | 跑酷路边石头 |
| 天空背景 | `models/backgrounds/` | panorama | 角色贴图 |
| UI 图 | `mobile_home/ui_*` 等 | 头像、任务图标 | 3D 模型 |

**距离约定（环境物）**

- **midground**：贴路两侧，玩家能看清细节，可轻量遮挡，一般无硬碰撞或仅装饰碰撞。  
- **distant**：远景剪影/地标，缩放大、无碰撞。  
- **buildings**：据点关卡或探索场景中的主体建筑，可有简单碰撞。

## 5. 命名规范

```
<角色或物体>_<动作或变体>.glb

elsa_idle.glb          ✅（目录已是 elsa/ 时也可简写 idle.glb）
rook_run_01.glb        ✅
jump_holographic_bar.glb   ✅（在 obstacles/jump/ 或 styles/holographic/）
障碍物-需跳跃.glb       ❌ 改用 jump_barrier_01.glb
rook跑步1 左腿蹬地….glb ❌ 改用 run_01.glb，说明写 README
```

- 版本/批次不要进路径（禁止 `0803/`、`第二批/` 作为正式目录）。  
- Tripo 节点名、UUID 长文件名：入库时**重命名**，原文件可丢进 `_inbox/tripo_raw/`。  
- 同一玩法多皮肤：`jump_barrier_holo.glb` / `jump_barrier_desert.glb`，或放 `styles/<theme>/`。
