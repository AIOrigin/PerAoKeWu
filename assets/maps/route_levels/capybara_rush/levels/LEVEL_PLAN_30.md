# Capybara Rush · 30 关规划

> **状态**：Phase 1 已落地（2026-08-10）— 30 关 JSON + 五主题 + 选关/跑速/断崖读表；Tripo 主题资产脚本运行中。  
> **范围**：叠塔 Stack 模式 · 30 关 · **5 种基调**  
> **原则**：关卡数据与主题皮肤分离；先数据驱动再补 Tripo 模型；不与星火信使 `runner_60s` 混目录。

---

## 0. 目标一句话

做出 **30 个可切换关卡**：玩法同一套（换道 / 跳 / 叠塔 / 断崖跳跳床），但用 **5 套基调** 区分天空、路面、路边风景、障碍外观与局部机关组合，让进度感明显、不审美疲劳。

---

## 1. 设计约束（沿用现有手感）

| 项 | 约定 |
|----|------|
| 玩法核 | 三道换道 + 空格跳矮障 + 断崖前跳跳床 + 撞障按高度掉层 |
| 不可出现 | 三道全部无法跳过/无法换道躲开的死墙 |
| 跳跳床 | **仅断崖前**；每关断崖数量由关卡数据控制（前期 0～1，后期最多 2） |
| 时限（可选） | 目标单关体感 **≤25s**（短轨高速）或无时限冲终点；首版先「到终点即过」 |
| 失败 | 只剩 1 只再撞障 / 掉下断崖 |
| 目录 | 关卡 JSON → `capybara_rush/levels/`；模型 → `capybara_rush/models/` |

## 3. 难度设计：以速度为主轴

当前原型 `RUN_SPEED = 12`。正式 30 关里，**跑速是第一难度旋钮**——同样障碍，更快 = 换道/起跳窗口更短、断崖容错更薄。

### 3.1 速度档位

| 档 | 体感星 | `run_speed` | 相对现原型 | 用途 |
|----|--------|-------------|------------|------|
| S0 | ★ | **9.5～10.5** | −20%～−12% | 教学：学操作，不拼手速 |
| S1 | ★★ | **11.0～12.0** | 约持平 | 巩固换道 / 首次断崖 |
| S2 | ★★★ | **12.5～13.5** | +4%～+12% | 牧场节奏、开始吃反应 |
| S3 | ★★★★ | **14.0～15.0** | +17%～+25% | 高柱 + 提速；霓虹开篇 |
| S4 | ★★★★★ | **15.5～17.0** | +29%～+42% | 双崖、终盘 Boss 感 |

规则：

1. **主题切换关可略降速**：换新皮肤/新机关的第一关（07 / 13 / 19 / 25）比上一关测评关慢半档，先认环境再加速。  
2. **新威胁与满速错开**：首次断崖（05）、首次双崖（21）不当关最高速；满速留给已熟悉该威胁后的测评关。  
3. **轨长随速度微调**：目标单关体感约 **22～28s**（无强制时限时仍按此调 `track_length ≈ run_speed × 24`）。  
4. **其它轴配合速度**：高速关优先加「密度 / 错道」，高柱关可略降速，避免「又快又瞬间掉 4 层」过虐。

### 4.3 `hazard_pattern` 预设名（程序表）

| pattern | 含义 |
|---------|------|
| `tutorial` | 极稀、无高柱、无断崖 |
| `intro_cliff` | 中稀 + 1 断崖 |
| `pasture_weave` | 栅栏错道为主 |

| `neon_dense` | 条纹密、速度感 |
| `volcano_gauntlet` | 双崖 + 高柱混合 |

具体刷怪仍走现有 `_spawn_hazards` 规则引擎，改为读 pattern + 参数，而不是写死在脚本。
