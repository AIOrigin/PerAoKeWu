# Capybara Rush 音频

把文件放在本目录即可（文件名保持一致，或改 `model_paths.gd` 里的路径）：

| 文件 | 用途 |
|------|------|
| `bgm_run.wav` / `.ogg` | 跑酷背景音乐（循环） |
| `sfx_fruit.wav` / `.ogg` | 碰到水果 |
| `sfx_hit.wav` / `.ogg` | 碰到障碍物 |
| `sfx_pickup.wav` / `.ogg` | 叠到路上的水豚（可选） |

建议：
- 音效用短 `.wav` / `.ogg`（0.1–0.4s）
- BGM 用可循环的 `.ogg`，响度比音效低一些
- 当前仓库里是程序生成的占位音频，可随时替换成正式素材

免费素材可搜：Kenney Audio、OpenGameArt、Pixabay（注意授权）。
