## 2. 设计尺寸与缩放规则

Home页使用竖屏9:16画布。所有布局坐标均以 **1440 × 2560（2x）** 为设计基准；客户端可按屏宽等比缩放，并以 **720 × 1280（1x）** 作为逻辑布局基准。顶部安全区和底部导航栏需适配设备刘海、状态栏与手势条，不能直接依赖物理屏幕边缘。

**铺设建议**：

- 背景图应使用 `cover` 模式铺满整个屏幕，不应平铺或重复。
- 背景图锚点应为屏幕中心，确保异形屏（刘海、挖孔、手势条）下的视觉平衡。
- 顶部HUD与底部导航栏应单独处理安全区避让，不依赖背景图的安全区处理。
- 所有UI组件（按钮、文本、进度条）应在背景之上以独立层渲染，支持后续动态更新。

## 4. 背景图适配与缩放规则

### 4.0 屏幕宽度自适应

背景图应根据设备屏幕宽度等比缩放，保持1440:720的宽度比例关系。客户端应在运行时检测屏幕宽度，按以下规则加载资源：

| 屏幕宽度范围 | 推荐加载资源 | 缩放因子 | 说明 |
|---|---|---|---|
| ≤ 375px | 1x (`720×1280`) | 0.5x | 小屏手机，使用1x资源直接显示或进一步缩放。 |
| 376–414px | 1x (`720×1280`) | 0.52–0.58x | 中等屏幕，1x资源缩放至屏幕宽度。 |
| 415–480px | 2x (`1440×2560`) | 0.29–0.33x | 大屏手机，2x资源缩放至屏幕宽度；或加载1x后放大。 |
| ≥ 481px | 2x (`1440×2560`) | 0.33x+ | 平板或宽屏，2x资源缩放至屏幕宽度。 |

**推荐实现**：

- 在应用启动或屏幕方向改变时，根据 `Screen.width` 或 `DisplayMetrics.widthPixels` 计算缩放因子。
- 对于宽度 ≤ 414px 的设备，优先使用1x资源以减少内存占用；对于宽度 > 414px 的设备，优先使用2x资源以保证清晰度。
- 使用 `Image.ScaleType.CENTER_CROP` 或等效方式，确保背景图始终覆盖整个屏幕，不出现空白边。

### 4.1 异形屏与安全区处理

背景图本身可延伸至屏幕物理边缘，但顶部HUD与底部导航栏必须单独避让系统安全区：

| 安全区类型 | 处理方式 | 说明 |
|---|---|---|
| 顶部状态栏 / 刘海 | HUD顶部距屏幕顶部 ≥ 系统状态栏高度 | 背景图可铺至顶部；HUD应有额外上边距。 |
| 底部手势条 / 虚拟导航栏 | 底部导航栏底部距屏幕底部 ≥ 系统导航栏高度 | 背景图可铺至底部；导航栏应有额外下边距。 |
| 挖孔屏 / 异形屏 | 背景图不应包含关键信息在挖孔区域 | 背景图已设计为中心对称，挖孔区域为天空或非关键区域。 |
